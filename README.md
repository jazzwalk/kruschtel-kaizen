# Kruschtel-Kaizen

Ausmist-App: Raum für Raum, jeden Tag ein kleiner Schritt. Mit Kurumi, dem Eichhörnchen, das früher alles gehortet hat.

- Räume, Methoden (KonMari, 4-Kisten, Minimalism Game, 12-12-12, Döstädning, 20/20-Regel, FlyLady) und Tempo wählen, Plan wird ausgewürfelt
- Jeden Tag eine Aufgabe, 5-Minuten-Einsatz, eigene Aufgaben
- Zähler, Abgabe-Liste mit Spenden- und Verkaufsportalen, Kalender, Abschlusskarte zum Teilen
- Aufräumtyp nach den Clutterbug-Stilen von Cas Aarssen

Läuft als installierbare Web-App (PWA) über GitHub Pages. Alle Daten bleiben lokal im Browser.
